# Mod viewer demo

This directory contains harmless examples to open in repository viewer mods.

## Try a viewer

From this directory, start Claude Code with an absolute plugin path:

```sh
claude --plugin-dir ../../mods/csv-table
```

Run `/csv-table` to read `data.csv`. Other viewers use `package.json`, `README.md`, `app.log`, `.env.example`, `before.txt`, or `after.txt`.

## Text animation

`animation.txt` has two ASCII frames separated by a form feed. Load it in `/ascii-flipbook`, then press Play. No video decoder is required.

### Sample values

All data is invented for demonstrations. No credentials or actual user records are included.
